### Changed
- Epic's browser no longer forces WebGPU software rendering inside Docker, and packaged containers are capped at two CPUs by default.
- The unattended focus guard remains active throughout scheduled runs so Docker Desktop cannot interrupt a full-screen application after startup.

### Fixed
- Epic security checks inside the checkout frame now trigger the native CAPTCHA notification instead of leaving the run apparently stuck.
- Epic's cross-origin **Add to library** button now receives trusted browser input rather than an ignored synthetic click.
- Current-run status no longer includes the previous run's completion time, and dashboard polling no longer floods debug logs.
