### Lontrium Control v1.8.0

- Added optional Microsoft Store/Xbox and Legacy Games support, including eligible Prime Gaming code redemption.
- Added a private game-code status panel, one-time update notice and a permanent offline release history in Help.
- Added central log redaction for credentials, accounts, tokens, private URL data, tracebacks and game codes.
- Capped Chrome cache at 250 MB and now requests a clean browser shutdown before terminating residual processes.
- Expanded AliExpress check-in recognition to 18 languages and added calendar confirmation.
- Added current and legacy Epic checkout-frame support and strict zero-total guards for Fab and Fanatical.
- Existing store selection, sessions, database, credentials and Windows schedule are preserved during update.

### Lontrium Control v1.7.4

- Fixed intermittent AliExpress login failures when the account is remembered and Chrome fills the password only after the field receives focus.
- Added support for the Portuguese **Entrar** and **Continuar** buttons in the AliExpress login flow.
- Changed **Stop all** to **Cancel run**: it cancels active/queued stores while keeping the Lontrium dashboard available.

### Lontrium Control v1.7.3

- Docker Desktop now stays in the background when Lontrium needs to start it.
- The launcher hides every Docker Desktop window, including delayed windows that never become the active window.
- Manual opens and scheduled runs use the same detached startup path.
- Docker remains untouched when it was already running before Lontrium.

### Lontrium Control v1.7.2

- Fixed scheduled runs at configured times incorrectly failing with a `409 Conflict` while the collection was actually starting.
- Removed the duplicate resource check inside Docker for Windows-hosted schedules.
- Added a local diagnostic log for launcher failures at `%LOCALAPPDATA%\Lontrium Control\scheduled-run.log`.
- Improved the failure notification so it explains where to find the underlying error.

### Lontrium Control v1.7.1

- Fixed Settings layout on narrow windows: long labels wrap and horizontal clipping is removed.
- Added a clear Browser login configuration action to every selected store section.
- Simplified dashboard store rows by removing repeated authentication guidance.
- Restored Brazilian Portuguese accents across Help and Settings descriptions.
- Fixed the literal {version} placeholder in the Settings header.

### Lontrium Control v1.7.0

- Settings now shows the installed version and only the selected store modules.
- Added Help with the reusable six-step introduction, browser-session guidance, optional credential explanations and localized tooltips.
- Reworked store selection cards and authentication metadata for Shopee, Fab, GamerPower and optional autofill stores.
- AliExpress now preserves remembered login fields and waits for a confirmed session before falling back to manual Browser login.

### Added
- CAPTCHA and expired-login notifications now include **Open browser** and **Skip now** actions. A skipped store remains pending for the next scheduled time while the remaining stores continue.
- Notifications use the Lontrium icon and replace older alerts for the same store instead of accumulating duplicates.

### Changed
- Scheduled Windows runs start through the native windowless helper, so no CMD or PowerShell window interrupts full-screen applications.
- AliExpress login recovery uses a normal Windows notification instead of a topmost modal dialog.

### Fixed
- Fatal store errors remain pending rather than being recorded as successful empty runs.
- Scheduled cleanup reliably releases only resources started by Lontrium after failures and timeouts.
- Epic and Fab checkout recovery handles stalled frames, browser failures and challenge retries more reliably.
